# Filtro Python — Gestión de usuarios

Aplicación de consola en **Python** para administrar usuarios: crear, editar y eliminar registros, asignarles categoría y navegar menús de administración (gestión, historial, servicios y fidelización). Los datos se guardan en un archivo **JSON**, así que persisten entre ejecuciones.

## Ejecutar

```bash
python main.py
```

Requiere Python 3; no usa librerías externas.

## Archivos

- `main.py` — menú y lógica de la aplicación (carga y guardado con el módulo `json`).
- `usuarios.json` — almacenamiento de los datos.

## Stack

`Python 3` · `JSON`
